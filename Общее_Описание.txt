ОБЩЕЕ ОПИСАНИЕ АИС «SALON-MASTER»

1. НАЗНАЧЕНИЕ СИСТЕМЫ
АИС «Salon-Master» предназначена для автоматизации учёта клиентов, услуг и заказов парикмахерской ИП «Стиль-Сервис».

2. ОСНОВНЫЕ ФУНКЦИИ
- Регистрация клиентов (ФИО, дата регистрации)
- Ведение каталога услуг (наименование, категория М/Ж, базовая стоимость)
- Фиксация заказов (клиент, услуга, мастер, дата)
- Автоматический расчёт скидки 3% для клиентов с 5-го визита
- Формирование отчётов по выручке

3. ПОЛЬЗОВАТЕЛИ
- Администратор
- Мастер-парикмахер
- Бухгалтер
- Директор

4. ТЕХНОЛОГИИ
- PostgreSQL
- Python (Django/FastAPI) или C# (.NET Core)
- Windows 10/11, Windows Server / Ubuntu Server
