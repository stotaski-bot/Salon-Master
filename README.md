# Salon-Master

Автоматизированная информационная система для парикмахерской «Стиль-Сервис».

## Назначение
- Учёт клиентов и истории их визитов
- Каталог услуг (стрижек) с ценами
- Автоматический расчёт скидки 3% для постоянных клиентов (начиная с 5-го визита)
- Фиксация оказанных услуг
- Формирование отчётов по выручке
